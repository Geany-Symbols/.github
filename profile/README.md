## Core Geany Features

- **A Text Editor for Code:** Open a source file you are allowed to change. Syntax colors help you read it. They do not compile it by themselves.
- **Save Before You Run:** A build uses the file on disk. An unsaved buffer is not what the compiler sees.
- **A Build You Configured:** Point the build command at a compiler you installed, for a project you wrote or were asked to work on.
- **A Folder You Know:** Keep the project in a directory you can explain. Do not edit files inside a system directory to "try a tweak."

---

## About Geany

Geany is a lightweight editor for code and other plain text you are writing. A script, a small program, or notes that happen to be code can live in one window. It does not grant a license to a closed-source tree you do not have rights to modify, and it does not connect to someone else's machine.

The useful habit is save, then build, then read the error. An error line number refers to the saved file. If you have not saved, you are debugging a version that is not on disk. Use a project folder. Running an unsaved scratch from a temporary path makes the next error harder to find.

A terminal command Geany launches is still a command. Read it before you bind it to a key. Do not point a build at a script you downloaded and have not read.

## Getting Started with Geany

Prerequisites: A folder for the project, and a compiler only if you intend to build.

1. **New File:** Save it in that folder with the right extension.
2. **Write a Few Lines:** Save again.
3. **Build Only If You Set a Command:** Read the command first. Then read the error output.
4. **Reopen the File:** Confirm the edit survived a close.

## Professional & Personal Use Cases

- **A Script You Wrote:** Edit, save, and run it from the folder you chose.
- **A Small Fix You Were Asked to Make:** Change the copy in your project, not a system file.
- **Notes in Plain Text:** A file you can open anywhere, saved under a clear name.
- **A Shared PC:** Close the project if the source is not for the next person.
